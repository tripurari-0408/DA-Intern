## 🎯 Objective
The objective of this assignment is to establish a strong foundation in core Python programming for Data Analytics. The work covers fundamental syntax, variable declarations, type checking, arithmetic operators, control flow logic, loop constructs, custom functions, data collections (Strings, Lists, Tuples, Dictionaries, Sets), basic file handling, and a terminal-based Student Record Management System project.

## 📑 Detailed Task Breakdown & Specifications

### Task 1: Python Basics (10 Marks)
* **File:** `task1_basics.py`
* **Requirements:**
  * Print a welcome message to the user.
  * Take user input for `Name`, `College Name`, and `Branch`.
  * Display the entered details using structured string formatting (`f-strings`).

---

### Task 2: Variables & Data Types (10 Marks)
* **File:** `task2_datatypes.py`
* **Requirements:**
  * Declare variables across four core data types:
    * **Integer (`int`)**
    * **Float (`float`)**
    * **String (`str`)**
    * **Boolean (`bool`)**
  * Print each variable value alongside its exact type using Python's built-in `type()` function.

---

### Task 3: Operators (10 Marks)
* **File:** `task3_operators.py`
* **Requirements:**
  * Create a CLI calculator program taking two numerical inputs from the user.
  * Perform and output results for:
    * **Addition (`+`)**
    * **Subtraction (`-`)**
    * **Multiplication (`*`)**
    * **Division (`/`)**
    * **Modulus (`%`)**

---

### Task 4: Conditional Statements (10 Marks)
* **File:** `task4_conditionals.py`
* **Requirements:**
  * Accept student marks as input.
  * Implement decision-making logic using `if`, `elif`, and `else` to assign grades based on the following scale:
    * **90+** $\rightarrow$ Grade A
    * **75 – 89** $\rightarrow$ Grade B
    * **60 – 74** $\rightarrow$ Grade C
    * **Below 60** $\rightarrow$ Fail

---

### Task 5: Loops (10 Marks)
* **File:** `task5_loops.py`
* **Requirements:**
  * Write a program using a `for` loop to print numbers from 1 to 20.
  * Write a program to generate and print the multiplication table of any user-input number.
  * Write a program using a `while` loop to print all even numbers between 1 and 50.

---

### Task 6: Functions (10 Marks)
* **File:** `task6_functions.py`
* **Requirements:**
  * Create a user-defined function to compute the square of a single number.
  * Create a user-defined function to calculate the average of three numbers.
  * Accept inputs dynamically from the user and call both functions to display the results.

---

### Task 7: Strings & Collections (15 Marks)
* **File:** `task7_collections.py`
* **Requirements:**
  * **Strings:** Demonstrate string manipulation methods (`upper()`, `lower()`, `replace()`, `find()`).
  * **Lists:** Demonstrate list mutation techniques (`append()`, `remove()`, `sort()`).
  * **Tuples:** Demonstrate tuple creation, immutability concepts, and positional indexing.
  * **Dictionaries:** Create and display key-value pairs representing student profile data.
  * **Sets:** Demonstrate set uniqueness and manipulation operations (`add()`, `remove()`).

---

### Task 8: Basic File Handling (10 Marks)
* **File:** `task8_file_handling.py`
* **Requirements:**
  * Create a new text file (`.txt`) programmatically.
  * Write a personal introduction paragraph into the file using write mode (`'w'`).
  * Read the contents back using read mode (`'r'`) and display the output on the console.

---

### Task 9: Mini Python Project — Student Record Management System (15 Marks)
* **File:** `task9_mini_project.py`
* **Requirements:**
  * Build a terminal-based Student Record Management System using lists and dictionaries.
  * **Features Included:**
    1. ➕ **Add Student:** Collect and append new student details (ID, Name, Branch, Marks).
    2. 📋 **Display All Records:** Formatted output listing all current student records.
    3. 🔍 **Search Student:** Search and display student details by name.
    4. ❌ **Delete Record:** Remove an existing record from the system by student name or ID.
